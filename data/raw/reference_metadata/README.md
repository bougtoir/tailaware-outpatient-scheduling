# Archived reference and submission-guidance sources

Each timestamped directory retains original HTTP-response bytes and a
machine-readable `acquisition_ledger.json` with source URL, identifier,
retrieval time, conditions, HTTP status, byte count, checksum, and terms.
The four acquisition attempts are retained; no earlier snapshot was replaced.

Crossref DOI metadata JSON and the acquisition ledgers are included in the
public research mirror. Publisher HTML snapshots are retained in the private
`bougtoir/wip` project and excluded from the public mirror. Their ledger entries
remain visible so the public archive does not imply that those HTML files are
distributed or that the inaccessible Omega guide was successfully retrieved.
