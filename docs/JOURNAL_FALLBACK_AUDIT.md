## Recommendation inputs for the gate

- COR is the strongest realistic fallback: its stated areas ("Production
  and Scheduling", "Decision-Making under Uncertainty and Data Analytics")
  match the paper's computational-OR identity; it publishes SAA/simulation
  + structural-observation papers; subscription route = no APC.
- POM is a plausible stretch fallback if the user prefers a
  management-science venue, but the Zhou et al. precedent makes reviewers
  there especially likely to ask "what is new beyond the known bound".
- HCMS is the safety option if healthcare framing is preferred over
  methodological framing.
- IJPE (added per addendum): viable third candidate — IF 10.0, hybrid,
  subscription route free; the value-of-information/value-of-complexity
  framing is a real IJPE-style contribution, but the production-economics
  center requires genuine reframing and its novelty bar is high.
  See docs/IJPE_POSITIONING_TEST.md and docs/JOURNAL_FIT_MATRIX_EJOR_COR_IJPE.md.
- EJOR remains viable only if a theorem closes (Phase-7 scorecard).

thinner than EJOR's; expected additions ~3–8 genuinely relevant COR papers
