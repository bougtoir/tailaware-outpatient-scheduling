## Fatal-weakness check

- EJOR: no proved novel theorem → likely repeats the Omega pattern
  (desk rejection on contribution level rather than quality).
- COR: no fatal weakness identified for the current + extension results.
- IJPE: "essential novel scientific contribution" + economic-consequences
  theme vs a healthcare OR simulation study → reframing risk, not fatal.

## Theory-outcome interaction (Addendum E)

- If a strong bound/theorem emerged (it did not): EJOR first, IJPE second
  (novelty bar satisfied), COR third.
- With the current modest-but-real structural results (frontier +
  boundary concentration + counterexamples): COR clearly best; IJPE
  viable with economic reframing; EJOR risky.
- The computational simplicity result's publication value is highest
  where computation itself is the contribution → COR.
